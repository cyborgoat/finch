# Finch

Local-first voice transcription. Audio is transcribed on your machine. Optional AI notes (summary, action items, …) send **transcript text only** to an LLM provider you choose.

- Upload (`.wav` `.mp3` `.m4a` `.webm` `.ogg` `.flac`) or record in the browser
- Local transcription with [Qwen3-ASR](https://huggingface.co/Qwen/Qwen3-ASR-1.7B)
- Optional speaker labels (diarization) and remembered speaker names (voiceprints)
- Markdown notes, written by hand or generated by an LLM
- English / 中文 interface

## Quick start

**You need:** [uv](https://docs.astral.sh/uv/), [ffmpeg](https://ffmpeg.org/) on your PATH, and [Node.js](https://nodejs.org/) 20+.

Finch runs as **three processes**. Open three terminals:

```bash
# One-time setup
cp .env.example .env
(cd backend && uv sync)
(cd frontend && cp .env.local.example .env.local && npm install)
```

| Terminal | Command | What it does |
|----------|---------|--------------|
| 1. API | `cd backend && uv run uvicorn app.main:app --reload` | Receives uploads, serves data |
| 2. Worker | `cd backend && uv run huey_consumer app.domains.jobs.queue.huey -w 1` | Does the actual transcription and AI note generation |
| 3. Web app | `cd frontend && npm run dev` | The UI at http://localhost:3000 |

> **Stuck on "Preparing" or "Queued"?** The worker (terminal 2) isn't running. The API only adds jobs to a queue; the worker processes them.

The first transcription downloads the ASR model, so it takes a while.

## Optional features

Turn these on in **Settings** in the app.

| Feature | Extra step |
|---------|-----------|
| AI notes | Settings → LLM provider: pick a provider and enter an API key (or a local Ollama URL) |
| Speaker labels | Put `HF_TOKEN=hf_...` in `.env`, accept the [pyannote model terms](https://huggingface.co/pyannote/speaker-diarization-community-1), then enable in Settings → Transcription. See [diarization](docs/diarization.md) |
| Speaker names | Requires speaker labels. Enable in Settings → Voiceprint profiles. See [voiceprints](docs/voiceprint-profiles.md) |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Job stays on "Preparing" / "Queued" | Start the worker (terminal 2) |
| `ERR_CONNECTION_REFUSED` on `:8000` | Start the API (terminal 1) |
| `ffmpeg is not installed` | `brew install ffmpeg` |
| `403` / `gated repo` | Accept the pyannote terms with the same Hugging Face account as your `HF_TOKEN` |

More in [docs/quickstart.md](docs/quickstart.md#troubleshooting).
